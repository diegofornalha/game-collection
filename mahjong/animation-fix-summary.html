🎮 Correção de Animações Mobile - Mahjong

❌ Problema Identificado

As animações no mobile estavam muito mais rápidas que no desktop, causando uma experiência inconsistente entre plataformas.

✅ Solução Implementada

Padronizei todas as durações de animação para garantir consistência visual entre mobile e desktop.

📋 Mudanças Realizadas

1. mobile.scss

❌ Antes: 
* {
  animation-duration: 0.2s !important;
  transition-duration: 0.2s !important;
}

Forçava TODAS as animações para 0.2s no mobile

✅ Depois: 
// Removido - permite que cada 
// componente defina sua duração

Cada componente controla sua própria duração

2. ViewContainer.vue

❌ Antes: 
transition: all 0.3s ease-out;
✅ Depois: 
transition: all 0.5s ease-out;

3. navigation/ViewContainer.vue

❌ Antes (Mobile): 
transition-duration: 0.25s;
✅ Depois (Mobile): 
transition-duration: 0.5s;

🎯 Resultado Final

  • ✅ Animações consistentes entre mobile e desktop
  • ✅ Velocidade mais suave e agradável (0.5s)
  • ✅ Experiência unificada em todas as plataformas
  • ✅ Código mais limpo e manutenível

📱 Teste

Para testar as mudanças:

  1. Acesse o jogo em http://localhost:3667/
  2. Teste em modo desktop (tela grande)
  3. Abra as ferramentas de desenvolvedor (F12)
  4. Ative o modo de dispositivo móvel (Ctrl+Shift+M)
  5. Compare as animações - devem ter a mesma velocidade
